# Mounted-YSWS

This branch was submitted as part of the 2026 Hack Club [Gap Year](https://manifesto.hackclub.com/) application for Round 2. This is a very rough, hard-coded, draft, with no real database, authentication, or translation support and is purely for demonstration purposes of the planned system and idea.

## Mounted?

> Build VR projects; start or upgrade your VR experience!

Mounted is a YSWS program where teenagers, new to VR or VR enthusiasts, build anything related to VR no matter the kind of project - with or without a VR headset already. This website is a proof of concept / demo of what the actual YSWS could look like and obviously includes lots of placeholders and hardcoded content, but it should give a good idea of what it might contain! <b>Best viewed on a PC!</b>


See my [one-pager document](https://docs.google.com/document/d/1n6WujJ7biXMl96pAEWMd7GNK2ZF_eDIAOCPiFbFdzT8/edit?usp=sharing) for the concept of the Mounted YSWS program, and visit the live page: [mounted-ysws.netlify.app](https://mounted-ysws.netlify.app)
